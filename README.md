# Картинки в чате — плагин Agents Hub

Картинки, которые приносит агент (пути в ответе, присланные файлы), — прямо в ленте:

- одна или две небольшие — как есть, в натуральную величину (не шире ленты);
- большая (больше 1000×750) или три и больше в одном сообщении — небольшими превью в ряд;
- клик по картинке — лайтбокс хаба: затемнение, листалка по картинкам сообщения (← →, свайп), Esc — закрыть;
- лайтбокс плавно вырастает из превью и уходит в него же; клик по картинке — зум в точку клика, увеличенную картинку
  можно таскать мышью; ховер и нажатие на превью и кнопках. С «уменьшить движение» в системе — только плавное появление.

Работает и в «Кратко», и в «Подробно». Сети и процесса у плагина нет.

## Поставить

«Настройки» → «Плагины» → вставить ссылку на этот репозиторий → «Проверить и поставить». Нужен хаб с API плагинов 1.10.

## Как устроено

Плагин только решает размер: следит за лентой, по сообщению считает его картинки и их размер и ставит класс — `ci-full`
(как есть) или `ci-thumb` (превью). Лайтбокс — штатный, хаба; плагин только добавляет ему движение и pan.

## Тесты

`python3 -m unittest discover -s tests` — стандартная библиотека, без хаба и браузера.
